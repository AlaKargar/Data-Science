### 📝 Instructions

1. Click the **Open in Colab** button for the notebook you want to run.
2. Wait for the notebook to open in Google Colab.
3. If prompted, sign in to your Google account.
4. Select **Runtime → Run all** to execute all code cells.
5. Wait for execution to finish and explore the outputs, tables, and visualizations.

**Note:** Some notebooks may require additional datasets or Python libraries. Follow any instructions provided in the notebook and make sure the required files are accessible in Google Colab.
